# Анимации и автообновление сайта — 0.8.15.post5

Вкладки и карточки появляются плавно, показатели подсвечиваются при изменении,
разделы настроек раскрываются с анимацией. Наведение на карточки и переключатели
имеет плавный переход. Системное предпочтение уменьшения движения учитывается.
Периодический опрос не запускает анимацию входа всех карточек заново.

Добавлен блок «Обновления сайта»: источник https://github.com/bsdedus/xlamBOT-TrioSafety,
ветка main, автоматическая проверка раз в 120 секунд и ручная кнопка проверки.
При первом подключении фиксируется исходное состояние GitHub, сохраняя текущие
неопубликованные локальные изменения. Последующие изменения ресурсов этой ветки
загружаются и применяются без перезапуска процесса бота.

Обновляются CSS, JavaScript и изображения/шрифты в static, иконки бойцов
в api/assets/brawler_icons и brawler_icons2, логотип images/xlambot_logo.png.
Модели, Python-код, игровые шаблоны, пользовательские конфигурации, история и
очередь не входят в это обновление. Изменения HTML-шаблонов требуют обновления
программы обычным установщиком.

Список файлов берётся из дерева GitHub, загрузка каждого файла привязана к
одному неизменному коммиту, размер и Git blob hash проверяются. Сначала готовится
полная новая версия в каталоге пользовательских данных, затем переключается
активная версия. При сбое остаётся прежняя рабочая версия. Ограничения запросов
GitHub учитываются с отсрочкой повторной проверки. Интервал выбран с учётом
[официальных ограничений GitHub API](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api).

Открытая страница проверяет локальный статус раз в 5 секунд. При изменении версии
она обновляется автоматически, возвращаясь на прежнюю вкладку. Несохранённая
форма откладывает обновление. Отключён периодический перерисовщик настроек,
который раньше мог сбросить ввод; редактируемые поля других вкладок также
защищены от фоновой перерисовки, пока находятся в фокусе.

Проверка: 123 теста прошли, JavaScript проверен синтаксически. Покрыты сохранение
локальных ресурсов при первом подключении, переключение полной версии,
отказ при неверном хеше, восстановление после перезапуска, ограничения путей
и источника, отсрочка при ограничении GitHub и сохранение новой версии программы.
В браузере на отдельной локальной проверочной панели воспроизведено обновление:
значение 0,25 сохранилось с уведомлением об ожидающем обновлении; после возврата
к сохранённым значениям страница сама обновилась и вернулась на вкладку настроек.
Подключение к настоящему GitHub подтверждено; найдено 220 файлов ресурсов.

Сборка установлена в текущую пользовательскую установку. Профиль MuMu сохранён,
бот возобновлён. Итоговая проверка версии, GitHub и видеопотока находится в
`.audit/resources_post5/verified_gui.json`. Публикация или изменение файлов
в репозитории GitHub в рамках этой работы не выполнялись.
